# Silly-Little-Python-Scripts
A silly little repo of potentially helpful python scripts. Maybe AI written ones in the future but that will be noted in the comments


## Silly-Little-Port-Scanner.py
```
usage: syn-scan.py [-h] -t TARGET -r {tcp,udp} -p PORT [-c COUNT] [-f {SA,S}]
options:
  -h, --help            show this help message and exit
  -t, --target TARGET   Target IP address
  -r, --protocol {tcp,udp}
                        Protocol to use only tcp and icmp are supported
                        currently
  -p, --port PORT       Port to scan
  -c, --count COUNT     Number of packets to send
  -f, --flags {SA,S}    Flags to send on a TCP scan
```
